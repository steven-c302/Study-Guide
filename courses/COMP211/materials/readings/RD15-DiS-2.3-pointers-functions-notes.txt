RD15 reading notes - Dive into Systems 2.3 (pointers and functions) - study notes written for this guide
Pass-by-pointer lets a function modify a caller's variable: the parameter is a pointer, and the value copied into it is the address of the caller's variable. Dereferencing the pointer parameter (*p = ...) changes the caller's variable, because the pointer stores the address of the caller's variable. A prototype such as void f(int *x); allows modification of an int passed by the caller, called as f(&x). Assigning to the pointer parameter itself (p = NULL or input = &y) changes only the local copy. Pass-by-value cannot modify the caller's variable because the parameter is copied into a new memory location. The pointer argument typically points into the stack frame of the calling function (for example main).
