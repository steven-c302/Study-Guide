RD14 reading notes - Dive into Systems 2.1 (parts of program memory) and 2.2 (pointers) - study notes written for this guide
Program memory is divided into parts: the code (text) segment holds the function instructions (main, max, change ...); the data segment holds global variables, which exist for the entire run; the heap holds dynamically allocated memory; the stack holds a stack frame for each active function call (parameters, local variables, return address). Space is allocated on the stack when a function is called and its frame is deallocated when it returns, so its locals become inaccessible. A local variable's scope is the function body in which it is declared, which is why two functions can each have a local named val. Global variables are generally discouraged because they reduce modularity and make debugging harder.
A pointer variable stores a memory address, not a primitive value. int *ptr; declares ptr as a pointer to an integer. The address-of operator & obtains a variable's address; the dereference operator * accesses the value stored at the address a pointer refers to. A valid initialization is int x; int *ptr = &x;. Assigning NULL to a pointer means it does not point to a valid memory location.
