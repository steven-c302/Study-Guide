RD13 reading notes - Floating point review: minifloat normalized vs denormalized (follow-up to RD11/RD12) - study notes written for this guide
For each value decide whether it is normalized or denormalized in the 8-bit minifloat (1 sign, 3 exponent bits with bias 3, 4 significand bits) and give the encoding. Try normalized first: write the value as 1.f x 2^e and compute the exponent field e + 3. If the field is 1 to 6 the value is normalized. If it is less than or equal to 0 the value is too small to be normalized, so it is denormalized: divide by 2^-2 (the fixed denormalized exponent 1 - bias) and write the result as 0.ffff with the exponent field 000. Examples: 1/32 is denormalized (0b0000_0010); -3/8 is normalized (0b1001_1000); 9/64 is denormalized (0b0000_1001); -3/4 is normalized (0b1010_1000).
