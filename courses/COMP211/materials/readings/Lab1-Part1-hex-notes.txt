Lab 1 Part 1 study notes (own summary; the handout itself is not republished)
Task: write hex.c, the opposite of xeh.c. It reads plain ASCII text until EOF and prints each character's two hex digits (0-9, A-F), then ends the output with a newline. Output of 80 or more hex digits wraps with a newline after every 80 digits.
Example: echo "Hello" | ./hex prints 48656C6C6F0A (echo adds a newline, which is 0A). echo -n "Hello" | ./hex prints 48656C6C6F. Pipes should round trip: echo "Hello" | ./hex | ./xeh prints Hello.
Splitting a byte into two nibbles uses bitwise operators: high nibble = byte >> 4, low nibble = byte & 0x0F. Turn a nibble 0 to 9 into '0' + nibble, and 10 to 15 into 'A' + (nibble - 10).
Testing reuses the Part 0 files in reverse: mkdir -p tests/hex/{input,expected,actual} (brace expansion makes three directories), cp the old expected files to the new input directory and the old input files to the new expected directory, rename *.expected to *.in with for f in *.expected; do mv "$f" "${f%.expected}.in"; done (${f%.expected} removes the suffix), then a hex_tests.sh script like xeh_tests.sh with basename "$input" .in, ./hex < "$input" > "$actual", and diff "$actual" "$expected" && echo "$base: PASS" || echo "$base: FAIL". Make it executable with chmod +x and run it as ./tests/hex/hex_tests.sh.
