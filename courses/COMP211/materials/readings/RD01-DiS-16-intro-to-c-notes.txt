RD01 reading notes - Dive into Systems 16.1 (getting started in C), 16.2 (input/output), 16.3 (conditionals and loops), 16.5 (arrays and strings) - study notes written for this guide
16.1 A C program is a set of functions with a required main. main returns an int (0 = success). Source files end in .c. Libraries are brought in with #include at the top of the file (for example stdio.h, math.h). C is procedural and has no classes; Java is object oriented and runs on a JVM, while C is compiled to a binary the OS runs directly.
Compile: gcc file.c makes a.out; gcc -o name file.c names the output; run with ./name. -Wall adds warnings, -g adds debug info, -lm links the math library. If compilation fails the executable is not rebuilt, but an older one may still exist.
Variables are declared before use: int x; char letter; float winpct; double pi; unsigned int y; int i, j, k;. Sizes: char 1, short 2, int 4, long 4 or 8, long long 8, float 4, double 8. sizeof gives the byte size (print with %lu).
'h' is a char (ASCII 104); "h" is a string literal. Integer division truncates (11 / 2 is 5, 11 / 2.0 is 5.5); % needs integers. x++ uses the value then increments; ++x increments first. Mixed int/float operations convert the int to float.
printf does not add a newline; write \n yourself.
16.2 printf takes a format string plus one argument per placeholder. %d decimal int, %g or %f float/double, %s string, %c character (shows the ASCII character for a numeric value). Escapes: \n newline, \t tab.
scanf reads values the user types and stores them at the memory addresses you give with &: scanf("%d", &num1). It skips whitespace between numeric values, is picky about format, and is not robust to bad input (it can loop forever; Ctrl-C ends it). stdio.h must be included.
16.3 if / else if / else work as in Java. C has no boolean type: 0 is false, any nonzero value is true. Relational operators == != < <= > >=; logical ! && ||. && and || short-circuit: evaluation stops as soon as the result is known. Use parentheses around complex conditions for readability.
Loops: while tests first; do-while runs the body at least once; for (init; test; step) evaluates init once, then test, body, step repeatedly. while and for are equally powerful. C has no enhanced for loop.
16.5 Arrays: int nums[10]; int small[] = {1, 3, 5}; capacity is fixed at declaration; valid indices are 0 to capacity-1. C does no bounds checking at compile time or run time: reading or writing past the end is undefined behavior.
Passing an array to a function passes its base address, so changes to elements persist in the caller; scalar parameters are copied. Functions usually take a size parameter because the array alone does not tell the function its capacity. void print_array(int arr[], int size).
Strings are char arrays ending in the null character '\0'; "hi" needs at least 3 chars. string.h: strlen (length without the null), strcpy (copies up to and including the null; destination must be large enough, otherwise undefined behavior and a security risk). printf %s prints characters until it reaches '\0'.
