RD17 reading notes - Dive into Systems 2.5 (arrays in C) - study notes written for this guide
Statically declared local arrays are stored on the stack. When an array is passed to a function the base address of the array is passed (not a copy), so modifying the array parameter changes the caller's array. Space for 50 ints is malloc(sizeof(int) * 50); malloc's return value is checked because it may return NULL. After free(p_array), setting p_array = NULL prevents dangling-pointer use. Array elements are stored contiguously (no gaps between elements): with a 4-byte int the address difference between iarray[2] and iarray[3] is 4. Constants rather than numeric literals are used for array sizes for readability and maintainability. A 2D array with 50 rows and 100 columns is int a[50][100]; a statically allocated 2D array is stored in row-major order. The column dimension must be specified in a 2D array function parameter so the compiler can compute element offsets. Method 1 of dynamic 2D allocation is a single malloc of rows*cols elements (all elements contiguous, an int * accessed as arr[i*M + j]; arr[i][j] cannot be used). Method 2 is an array of row pointers (an int ** whose elements, the rows, are separately allocated; only elements within a row are contiguous; arr[i] is an int *). Methods 1 and 2 differ in layout and type, so they cannot share one function parameter type.
