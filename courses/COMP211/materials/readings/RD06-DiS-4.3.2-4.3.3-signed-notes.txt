RD06 reading notes - Dive into Systems 4.3.2-4.3.3 (two's complement and bit extension) - study notes written for this guide
Two's complement represents signed integers: the most significant bit contributes a large NEGATIVE weight (-2^(n-1)) to the sum, so an MSB of 1 means a negative number. Arithmetic wraps around naturally between negative numbers and zero (so addition uses the same hardware as unsigned addition, with no special cases and only one zero), which is why it is superior to sign-magnitude and one's complement.
To negate a two's complement number: flip every bit and add one.
C declares int as a signed two's complement integer. printf with %d interprets the bits as signed and %u as unsigned, so the same variable can print -100 and 4294967196: the bit pattern is the same, the interpretation differs.
Bit extension: arithmetic needs operands of the same width, so a narrower value is extended before use (for example adding a 32-bit int and a 16-bit short). Sign extension repeats the most significant (sign) bit into the new high bits and preserves the value and sign of a two's complement number. Zero extension fills with zeros and is used for unsigned values; zero-extending a negative two's complement number changes its value.
