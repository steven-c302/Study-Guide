Pass by Value vs. Pass by Pointer
• Pass by value
• When length is passed to print_arr(), a copy of the value is sent
• Modifying length inside print_arr() does not affect the original variable in main()
• Pass by pointer
• When nums is passed to print_arr(), instead of copying the entire array, the address
of the array is sent
• Modifying nums inside print_arr() does affect the original array in main()

#include <stdint.h>
#include <stdio.h>
void modify_values(int8_t arr[], int8_t length) {
length = 99; // This change DOES NOT affect length in main()

Pass by Value vs. Pass by Pointer
Pass-by-Value Pass-by-Pointer
Pros
• Safety: The function cannot
modify the original variable.
• Simplicity: No risk of
unintended side effects.
• Efficient for large data types:
No extra memory allocation for
copies.
• Allows modification: The
function can directly modify the
original data.
Cons
• Performance overhead:
Copying large objects is
expensive in terms of time and
memory.
• More memory usage: Each
call creates a new copy of the
variable.
• Risk of unintended
modification: The function
can accidentally change the
original variable.

[Slide 60]
Arrays
• When you use an array name in an expression, it decays into:
• a pointer to the first element
• Pointer arithmetic moves by element size automatically.
• arr[i] is the same as *(arr + i)
60
#include <stdio.h>
int main() {
int arr[3] = {10, 20, 30};
int* p = arr; // same as &arr[0]
printf("%d\n", *p); // 10
printf("%d\n", *(p + 1)); // 20
printf("%d\n", *(p + 2)); // 30
return 0;
}
[Slide 61]
Pointer Arithmetic
• Pointer arithmetic allows you to move between memory locations that a
pointer can access.
• It’s based on the size of the data type the pointer refers to.
61
int arr[3] = {10, 20, 30};
int *p = arr;
Expression Meaning Result
p address of arr[0] (points to 10)
p + 1 address of arr[1] (points to 20)
*(p + 2) value at arr[2] 30
When used in an expression, the name of an
array (like arr) automatically becomes a pointer
element 0.
[Slide 62]
Pointer Arithmetic
• Only valid within the same array (undefined outside).
• Pointer increments depend on data type size
• (p + 1 adds sizeof(*p) bytes).
• Works with all pointer types (e.g., int*, double*, etc.).
62
Operation Description
p + n Move forward n elements
p - n Move backward n elements
p1 - p2 Returns the number of elements
between two pointers
p++ / p-- Move to next / previous element
