- Never used in practice anymore
- Mainly taught as a steppingstone towards understanding two’s complement
- Two’s complement
- Widely used for representing signed integers

- Used only when non-negative values are needed

Overflow in the Physical World
- Imagine a speedometer with only 3 digits.
- The range of values it can display is [000, 999]
- If you’re at 999 and increase by 1, it doesn’t show 1000 (because there are only 3 digits)
- Instead, it wraps back around to 000
- This “wrapping around” is exactly what happens with integer overflow in
binary numbers!

How Numbers Are Stored in Your Programs
- Signed numbers are encoded using 2’s complement
- Unsigned numbers are encoded using unsigned binary
- For example, let's store -1 as an 8-bit number
- The value would be stored at 0b1111_1111.
- If interpreted as a signed number, it represents -1.
- If interpreted as an unsigned number, it represents 255.
