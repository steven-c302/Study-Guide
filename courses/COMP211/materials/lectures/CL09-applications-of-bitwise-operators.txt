Masks
• A mask is a binary pattern used to select (get), set, clear, or toggle
specific bits within a number.
• Select(get) = read
• Set = make 1
• Clear = make 0
• Toggle = flip from 0 to 1 or 1 to 0

update_bit
• Write a function that will set bit i of num to x

#include <stdint.h>
#include <stdio.h>
int8_t update_bit(int8_t num, int8_t i, int8_t x) {
int8_t mask = ~(1 << i);
int8_t clear_bit_i = num & mask;
return clear_bit_i | (x << i);
}
int main(void) {
printf("%d\n", update_bit(0b0101, 2, 0));
printf("%d\n", update_bit(0b0101, 1, 1));
return 0;
}

Applications of Bit Manipulation
• Performance optimization in arithmetic operations
• Bit shifting is much more efficient than multiplying and dividing
• Example: To multiply a number x by 4
• x *= 4
• x << 2
• Used in: Embedded systems, game engines, and performance-critical code.

Hex Color Codes
• The values in an RGB color code represent the intensity of each color
channel. Each channel's intensity ranges from:
• 0 (0x00) → No intensity (the channel is completely off)
• 255 (0xFF) → Full intensity (the channel is at its maximum brightness)
