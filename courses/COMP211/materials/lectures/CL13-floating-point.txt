Floating Point Representation
• What is floating point representation?
• A way to represent very large and very small numbers efficiently
• A standard called IEEE-754 defines how modern systems handle these
values.
• We will start with simpler models (microfloat and minifloat) to build up to
IEEE-754.

In normalized form, 1 <= |significand| < 2
This means the value to the left of the binary point is always 1.
We can increase the precision by not storing this 1!
[Slide 6]
Implicit 1
• In normalized binary floating point, every (nonzero) number has a leading 1
before the binary point.
• Since that leading one is always there, we don’t need to store it
• Hence the name “Implicit 1”
• By not storing it, we free up one extra bit for the significand
• This extra bit increase precision
• The range is unaffected by this
• (Since the range is determined by the exponent bits)

Floating Point
• The full value is not stored directly
• Instead, we store
• Significand (without the leading one)
• Exponent
• This design allows for a much larger range of values
• But it in turn trades off precision

Design Tradeoffs
• There’s a tradeoff between how large or small a number you can represent
(range) and how accurately you can represent numbers (precision), both of
which are constrained by the total number of available bits.
• Precision vs Range
• More exponent bits increase the range of representable numbers but reduces the
number of bits available for the significand, decreasing precision.
• More significand bits increase the precision of the representation, allowing for more
precision, but reduce the number of bits available for the exponent, decreasing the
range.
