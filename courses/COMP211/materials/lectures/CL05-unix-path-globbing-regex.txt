What does ./hello actually mean?
- Remember that . means the current directory.
- So:
- $ ./hello
- is simply a relative path.
- You're telling the shell:
- Go into the current directory (.), find the file called hello, and execute it.
- It's conceptually the same as giving its absolute path:
- $ /home/alice/projects/hello
- Both commands tell the shell exactly where the executable is located.

Because that directory is in $PATH, you can run hello from any current working

[Slide 18]
Why isn't the current directory in $PATH?
- You might wonder: why doesn't the shell just search the current directory too?
- There's an important security reason.
- Imagine you download some files and enter the directory:
- $ cd ~/Downloads/suspicious-stuff
- Someone has put a malicious executable there called:
- ls
- If the shell always searched the current directory first, then when you innocently
typed:
- $ ls
- you could accidentally run:
- $ ./ls
- instead of the real system ls.

[Slide 19]
Why isn't the current directory in $PATH?
- By requiring:
- $ ./hello
- you're explicitly saying:
- Yes, I purposefully want to execute the hello program located right here.

Globbing
- Globbing is a way of using patterns to match groups of filenames instead of
typing them one by one.
- The shell (bash, zsh, etc.) expands these patterns before running the
command.
21
Pattern Meaning
* any number of characters
? exactly one character
[abc] one character from the set
[a-z] one character in a range
[Slide 22]
Globbing
- Globbing saves time and reduces mistakes
- For example, instead of typing
- rm file1.txt file2.txt file3.txt file4.txt
- You can type
- rm *.txt
- This command will delete all files in the current working directory that end
in .txt

How does globbing work in the shell?
- The shell expands filename patterns before running a command.
- For example, suppose a directory contains:
- cat.jpg
- dog.txt
- notes.txt
- photo.png
- If you type:
- cat *.txt
- The shell sees *.txt, searches the current directory, and expands the command to
- cat dog.txt notes.txt
- Then it runs cat.
- Importantly, cat itself never sees *.txt.

Escaping
- In regular expressions, the dot (.) means “Match any single character (except
newline)”
- Escaping uses an escape character (often \) to change how the character or
sequence that follows it is interpreted.
- Escaping tells the regex engine: “I want this character itself, not what it
normally means.”
34
[Slide 35]
Brief Aside: Escaping Is a General Concept
- We have also seen escaping with special characters!
- In many programming contexts, certain characters have a special meaning.
- A backslash (\) can be used to change how the character that follows it is
interpreted.
- For example, in C:
- printf("Hello\nWorld");
- \n is interpreted as a newline, rather than the two characters \ and n.

The find Command
- find searches the filesystem for files or directories
- It starts at a given directory and searches recursively
- Results are based on conditions such as:
- File name
- File type
- Size, time, permissions (and more)
41
[Slide 42]
find –name Format
- find <where to search> -name <pattern>
- Example:
- find ./ -name dog.c
- ./ = start searching from the current directory
- -name = match files by name
- dog.c = exact file name to match
- find uses shell-style glob patterns, not regular expressions

The grep Command
- grep searches for text patterns inside files
- It scans file contents line by line
- Often used to find:
- Variable names
- Error messages
- Specific words or phrases
50
[Slide 51]
grep Syntax
- grep <pattern> <file>
- Example:
- grep "main" dog.c
- Searches for the word main
- Looks inside the file dog.c
- Prints matching lines
- grep uses regular expression patterns
