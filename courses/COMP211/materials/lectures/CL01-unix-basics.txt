Real-time input & output
- Introducing: Teletypes (TTYs)
- Originally designed for telegraph networks
- Engineers created the first interactive
text interface using teletypes.
- A human would use the keyboard to type
characters to send to a computer
- The computer would send characters back
and they would be printed out line by line
on paper.
- Teletypes connected to computers
were often called:
- Console terminals
- Teletype terminals

How Terminal Interaction Works
- A terminal session follows a simple loop:
- Prompt appears
- User types a command
- Presses Enter
- Computer responds with text
- Prompt appears again
- This style is called a command-line interface (CLI).

Unix
- Unix is a family of operating systems.
- The operating system is the “boss” of your computer.
- It manages memory, files, programs, and hardware.
- Many modern systems are based on or inspired by Unix.
- Eg. macOS is a Unix operating system
24
[Slide 25]
File System
- File system: the way an operating system organizes and stores files.
- Most operating systems use a hierarchical (tree-like) structure.
- Root
- At the top of the tree is the root directory.
- On Mac/Linux, this is /
- On Windows this is a drive letter like C:\
- Directories (Folders)
- Directories act like branches in the tree.
- They can contain files or other directories (subdirectories).
- Files
- Files are the leaves of the tree.
- A file stores data (text, images, programs, etc.).

- Always unique

- A path that starts from the current working directory
- Parent directory: .. (two dots)
- Current directory: . (one dot)

Hidden Files and Directories
- A hidden file or directory is one whose name begins with a dot (.).
- Examples
- .git/
-
.vscode/
-
.bashrc
- Purpose:
- Store user/application configuration files
- Keep clutter out of normal directory listings
- Visibility:
- Normal ls won’t show them
- Use ls -a to display hidden files and directories
