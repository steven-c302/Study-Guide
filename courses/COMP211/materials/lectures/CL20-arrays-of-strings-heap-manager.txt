static void free2d(int** a, int rows) {
if (a == NULL) {
return;
}
/* Free each separately allocated row */
for (int i = 0; i < rows; i++) {
free(a[i]);
}
/* Free the array of row pointers */
free(a);
}

Heap Memory Management
•The heap memory manager maintains a free list which contains the start
address and size of contiguous unallocated blocks of memory in the heap.
•Initially, the heap consists of a single large free block, so the free list contains
one entry representing the entire available heap.
•After performing a series of malloc and free operations, the heap can become
fragmented (free spaces end up scattered among allocated blocks).

[Slide 31]
First Fit Allocation Strategy
•This example used the first fit allocation strategy, in which the allocator
•Starts at the beginning of the free list and checks each free block one by
one.
•Selects the first block that is large enough to accommodate the request.
•If the chosen free block is larger than needed, it may be split into two
parts:
•one part is allocated
•and the remaining part is left in the free list as a smaller free block.

Resizing Arrays
•Arrays are stored contiguously, meaning each element sits directly next to
the one before it in memory.
•When an array is stored on the stack, its size is fixed and cannot be
changed. This is because there may already be other data occupying the
memory immediately after the array, leaving no room to expand it in place.

Realloc
•Stack arrays cannot be resized, but heap arrays can be resized with realloc
•realloc stands for reallocate. It's a function that changes the size of a block of
memory previously allocated on the heap.
•Under the hood, realloc can do one of two things (covered on the next slides)

[Slide 43]
Case 1: Room to Grow in Place
•If there's space directly after the current memory block, realloc just expands
the block in place.
43
[Slide 44]
Case 2: No room - must move
•If there’s not enough room after the current block (maybe something else is in
the way), realloc will:
1. Allocate a new block of the requested size.
2. Copy the contents from the old block to the new one.
3. Free the old block (if successful).
4. Return a pointer to the new block.

[Slide 52]
fgets
•fgets reads a line of input from a given stream (stdinin this case) and
stores it in the buffer you provide.
•The second argument (sizeof(buffer)) tells fgets the maximum number
of characters to read, including the null terminator (\0).
•If the input fits in the buffer, it’s stored as a null-terminated string.
•If the input is longer than the buffer, only part of it is read, and the rest
remains in the input stream to be consumed later.
•fgets returns the same pointer you passed in (buffer) on success, and
NULL on failure (e.g., if end-of-file is reached or an error occurs).

read_names
•The function read_names dynamically allocates and fills a 2D array of
characters (an array of strings) by reading a specified number of names from
the user.
•char** read_names(int num_names, int name_len);
•Parameters
•num_names: The number of names the function should read.
•name_len: The maximum length allowed for each name (not including the null
terminator).
•Return Value
•Returns a char** (a pointer to an array of char*).
•Each char*in the array points to a dynamically allocated string containing one name.
•The caller is responsible for freeing all allocated memory.

array_of_strings.c
•This program builds a dynamically growing array of strings.
•It repeatedly asks the user to enter words.
•Each word is stored on the heap.
•The program keeps the words in a dynamically resized array of char * pointers.
•If the array fills up, it doubles its capacity using realloc.
•When the user types "quit", the program:
•Prints all stored words.
•Frees all allocated memory.
