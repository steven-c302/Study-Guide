Left Shift
- Syntax
- number << n
- Effect:
- Shifts all bits to the left by n places.
- Fills the rightmost n bits with 0s.
- Equivalent to multiplying the number by 2n
.

[Slide 9]
Logical Right Shift
- Used for unsigned numbers
- Syntax
- number >> n
- Effect:
- Shifts all bits to the right by n places.
- Fills the leftmost n bits with 0s.
- Equivalent to integer division by 2n, truncating any decimal part.
9

uint8_t d = a >> 3;
b = 0b0000_0010 = 2
c = 0b0000_0001 = 1
d = 0b0000_0000 = 0
[Slide 11]
Arithmetic Right Shift
- Used for signed numbers
- Syntax
- number >> n
- Effect:
- Fills the leftmost n bits with a copy of the msb.
- Equivalent to integer division by 2n, rounding towards negative infinity.
- In C, unsigned right shifts are logical, while signed right shifts are
implementation-defined (usually arithmetic).

Masks
- A mask is a binary pattern used to select (get), set, clear, or toggle
specific bits within a number.
- Select(get) = read
- Set = make 1
- Clear = make 0
- Toggle = flip from 0 to 1 or 1 to 0
