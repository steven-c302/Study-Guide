Binary
- There are two ways to indicate that a number is binary
- Prepend 0b
- Ex: 0b1001
- Subscript 2
- Ex: 10012
- Place binary numbers in groups of four to make it easier to read
- Normally, spaces are used when handwritten
- Ex: 0b1010 1111 0101
- And underscores are used for typed values
- Ex: 0b1010_1111_0101
- If you cannot evenly break up the number into groups of four, start making the groups
from the right
- Ex: 0b10_1010_0011

One’s Complement Shortcomings
- In one’s complement, zero has two representations:
- all zeros (000...0)
- all ones (111...1).
- This is a drawback because it wastes a possible bit pattern that could have
been used to represent an additional unique value.

Two’s complement decimal
- Step 1: Check the Most Significant Bit (MSB)
64
If the MSB is 0, the number is positive.
- Step 2: You can interpret it the same way as an unsigned binary
number.
If the MSB is 1, the number is negative.
- Step 2: Flip the bits (invert all bits: change 0 to 1 and 1 to 0).
- Step 3: Add 1 to the flipped bits.
- Step 4: The original number is the negative of this result.
