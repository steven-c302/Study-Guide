Normalized Exponent
7
For normalized numbers, the exponent is calculated as:
𝑒xponent = exponent field − bias
The smallest exponent field available to a normalized number is 001
because 000 is reserved for zero and subnormal numbers. So,
exponent = 0012 = 1
and:
exponent = 1 − 3 = −2
Therefore, the smallest normalized numbers have the form:
1.xxxx2×2−2

IEEE-754 Floating Point
• Inside your processor, there are specialized circuits called floating-point units
(FPUs).
• The FPU handles arithmetic (add, subtract, multiply, divide, square root, etc.)
directly in hardware, using IEEE 754 rules.
• That means the same floating-point calculation will behave the same way on
different machines (with the same precision), which is crucial for consistency
in programming, science, and engineering.

Floating Point Equality
• Floating-point numbers should not be compared using the == operator due
to rounding errors and precision loss!
• Instead, comparisons should use an epsilon-based approach to check if
two values are close enough.
• An epsilon (ϵ) is a small threshold value used to determine if two floating-
point numbers are "close enough" to be considered equal.
• The C standard library (float.h) provides machine-specific precision
constants:
• FLT_EPSILON (1.19209290e-7F) for float
• DBL_EPSILON (2.2204460492503131e-16) for double

What is an LLM?
31
• A Large Language Model (LLM) is a program that has been trained to
recognize patterns in large amounts of text.
• Given some text, it predicts what should come next.
• For example, given:
• The capital of France is ___
• the model might assign probabilities like:
• Paris 97%
• London 1%
• France 0.5%
•
...
• It then uses these predictions to generate text one piece at a time.
[Slide 32]
How does it learn these predictions?
• An LLM contains billions of numerical values called parameters (or weights).
• You can think of these values as numbers that control how strongly different patterns
influence the model's predictions.
• During training, the model sees many examples of text, makes predictions,
measures how wrong those predictions are, and adjusts its parameters.

Common Data Types: FP16
• FP16 stands for 16-bit floating point (also called half precision).
• Like the floating-point representations we've been using, FP16 divides its bits into
three fields:
• For a normalized FP16 number: −1 𝑆×1. 𝐹×2𝐸−bias
• The bias for FP16 is 15
• So, for example, if the exponent field contains:
• 100002 = 16
• the actual exponent is:
• 16−15=1

Why use FP16 instead of FP32?
• Imagine an LLM has 7 billion parameters.
• If they're all FP32:
• 7 billion×4 bytes≈ 28 GB
• If they're all FP16:
• 7 billion×2 bytes≈ 14 GB
• That's a huge difference when you're moving billions of values between memory and
processors.
• But there's a tradeoff!!!
• FP16 saves space by having fewer bits available for the exponent and fraction.
• So FP16 gives us less range and less precision than FP32.
• That means more numbers have to be rounded, and very large values can overflow more
easily.

Common Data Types: BF16
• BF16 stands for Brain Floating Point 16 (bfloat16).
• Designed for neural networks
• Like FP16, it uses 16 total bits, but it divides those bits differently:
• FP16 chooses: more precision, less range
• BF16 chooses: more range, less precision

[Slide 40]
BF16
• Why 8 exponent bits?
• There's an especially useful connection to FP32.
• FP32 uses:
• 1 sign | 8 exponent | 23 fraction
• BF16 uses:
• 1 sign | 8 exponent | 7 fraction
• They have the same number of exponent bits.
• They also both use an exponent bias of: 127
• So BF16 has approximately the same numerical range as FP32, but much
less precision.

Why would an LLM want more range?
• During neural-network calculations, values can vary considerably in
magnitude.
• If the exponent isn't large enough, you can encounter:
• Overflow: a value is too large to represent.
• Underflow: a value is too small to represent normally.
• BF16's 8-bit exponent gives it much more range than FP16.
• For example, the largest finite positive values are roughly:
• FP16 max ≈ 65,504
• BF16 max ≈ 3.39×1038
• That's an enormous difference in range!!!
