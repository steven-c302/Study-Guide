[Slide 16]
Arrays
- ndigit[c]++;
- This directly uses the character c as the array index. Since c represents the ASCII value of
the input character, the index will be between 48 and 57 for digits ('0' to '9’). ndigit only has 10
elements (indices 0-9), so this will index out of bounds.
- ndigit['c' - '0']++;
- The expression 'c' - '0' is incorrect because 'c' is treated as a literal character, not the value of
the variable c. 'c' - '0’ = 99 – 48 = 51
- ndigit[c - '0']++;
- This is the correct approach. Subtracting '0' from the character c converts the ASCII value of
the digit (e.g., 48 for '0', 49 for '1') to its numeric equivalent (e.g., 0 for '0', 1 for '1’).
- ndigit[c - 48]++;
- Subtracting 48 (the ASCII value of '0') from c is functionally equivalent to subtracting '0'. This
will correctly map the ASCII value of the digit to its numeric equivalent.
- While this works, it is less readable. Using '0' instead of 48 makes the intent clear.

I/O Redirection
- A file descriptor is a non-negative integer that uniquely identifies an open file
within a process.
- The operating system uses file descriptors to manage input and output resources such
as files, devices, and network connections.
- A file stream is a higher-level abstraction built on top of file descriptors. It
provides buffered input and output operations through standard library
functions.
- Every process begins with three open file streams by default:
- Standard input (stdin): the source from which a process reads its input
- Standard output (stdout): the default destination for normal program output
- Standard error (stderr): the destination used for error messages and diagnostics
19
[Slide 20]
I/O Redirection
- When a new process starts, these three streams are automatically opened
and associated with the following file descriptors:
- 0: stdin
- 1: stdout
- 2: stderr
- These default streams allow programs to communicate with the user and the
system without needing to explicitly open any files.

Default Behavior of stdout
- By default, stdout writes to the terminal
- You can change where stdout goes (redirection)
- Syntax:

command >> output_file
- This will append to output_file

Pipes
- A pipe connects the output of one command to the input of another
- It redirects:
- stdout of the first command
- to stdin of the second command
- Syntax
- command1 | command2
- command1 writes to stdout
- command2 reads from stdin

[Slide 49]
Why Pipes are Powerful
- Avoid intermediate files
- Encourage small, reusable commands
- Enable complex tasks with simple tools
- Pipes are heavily used in:
- Shell scripts
- Log processing
- Data analysis

String Reading Summary
- In C, strings are implemented as arrays of char values
- Every C string must end with a null terminator (‘\0’)
- The null terminator marks the end of the string in memory
- C provides a standard library for working with strings
- Included with #include <string.h>
- String-handling functions in this library rely on the null terminator to determine
where the string ends
- When printing a string using printf, use the %s format specifier

- The length of a string is not
necessarily the same as the
size of the array that stores it.
- strlen is used to count the
number of characters in a string
(excluding the null terminator)
- sizeof is used to determine
the total size of the array (in
bytes)

#include <stdio.h>
#include <string.h>
int main(void) {
/* 1. " " automatically includes a null terminator */
/* A sequence of characters enclosed in double quotes (" ") is
called a string literal. */
char str1[] = "hello"; // {'h','e','l','l','o','\0'}
/* 2. ' ' does NOT include a null terminator */
char str2[5] = {'h', 'e', 'l', 'l', 'o'}; // NOT a valid C string
/* 3. Character array larger than the string – totally fine */
char str3[10] = "hi"; // only uses 3 chars: 'h','i','\0'
/* 4. Null terminator placed early */
char str4[10] = {'h', 'i',
'\0', 'X', 'Y', 'Z',
'\0'};
/* Print strings */
printf("str1: \"%s\" (strlen = %lu)\n", str1, strlen(str1));
/* WARNING: Uncommenting this causes undefined behavior */
// printf("str2: \"%s\"\n", str2);
printf("str3: \"%s\" (strlen = %lu)\n", str3, strlen(str3));
printf("str4: \"%s\" (strlen = %lu)\n", str4, strlen(str4));
/* 5. Demonstrating array size vs string length */
printf("Array size of str3: %lu\n", sizeof(str3));
printf("String length of str3: %lu\n", strlen(str3));
return 0;
}
