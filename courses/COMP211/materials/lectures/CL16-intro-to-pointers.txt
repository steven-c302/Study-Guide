The Stack (Automatic Memory)
• The stack is used for each function’s stack frame
• Stack Growth
• Every time a function is called, a stack frame is pushed onto the stack
• This is done automatically (the programmer does not have to think about it)
• Grows from higher memory addresses to lower
• Stack Shrinkage
• When the function returns, its stack frame is popped off the stack
• This is done automatically (the programmer does not have to think about it)
• Stack Overflow
• If the stack grows too large (e.g., due to deep recursion or very large local variables), you
might encounter a stack overflow.

Modern Processors
• Most 64-bit CPUs use only 48–52 bits of their 64-bit address space.
• Why Not the Full 64 Bits?
• Hardware and OSes reserve upper bits for future use.
• 48-bit addressing already supports 256 TB.
• Plenty of room to grow as physical memory sizes increase.
• With 48 bits, the address space is limited to:
• 248 bytes
• (218 * 230) bytes
• 256 TB

What is a pointer
• A pointer is a variable that stores a memory address.
• The memory address is the location of the variable in memory.
• A pointer does not store the value! It stores where the value lives.
14
[Slide 14]
Why use pointers?
• Pointers allow us to
• Modify variables in another function
• Work with dynamic memory
• Build linked data structures
• Efficiently pass large data structures

Recall: Stack Pointer
• Stack Pointer (SP): A register that points to the current top of the stack (the location
where the most recent stack data was stored).
• Register: A small, fast storage location inside the CPU that holds data the CPU is
currently working with.
• As a program calls functions and uses the stack, the stack pointer changes to
indicate where the stack currently ends.
• On many architectures the stack grows toward lower memory addresses. So
adding data to the stack typically decreases the stack pointer, while removing data
typically increases it.

Double Pointers
• A double pointer is a pointer to a pointer
• int **dp;
• dp stores the address of an int *
• *dp is a pointer to an int
• **dp is an int
